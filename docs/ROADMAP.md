# Roadmap

## Phasen der Demo

| Phase | Inhalt | Stand |
|:---|:---|:---|
| 0 | Einrichtung: Projekt, Git, GitHub Pages, Supabase | Dateien angelegt, Build offen |
| 1 | Fundament: hell/dunkel, Navigation, Registrierung mit Einladungscode und Altersangabe, Anmeldung, lokaler Speicher mit Abgleich | offen |
| 2 | Check-in und Locations: Standortvorschlag, OpenStreetMap, Bewertung, Tags, Getränke, Ausgaben, Begleitung, Fotos | offen |
| 3 | Karte, Ranking, Location-Detail | offen |
| 4 | Dashboard, Diagramm-Baukasten, Meilensteine | abgeschlossen |
| 5 | Freunde, Feed, „Bin unterwegs“, Markieren mit Zustimmung, Push; danach Test auf den iPhones | Freunde, Feed, Unterwegs, Markieren, Foto-Freigabe gebaut, Test mit zweitem Konto offen; Push offen |
| 6 | Freunde-Empfehlungen, Kneipentour, Jahresrückblick zum Teilen | gebaut, Oberfläche noch nicht im Browser geprüft |
| 7 | Kontolöschung, Datenexport, Rechtstexte als Entwurf, Testplan | Export, Kontolöschung, Budget gebaut; Rechtstexte weiter Entwurf; Testplan offen |
